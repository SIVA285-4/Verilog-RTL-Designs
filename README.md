# Verilog-RTL-Designs

This repository contains a collection of Verilog RTL design projects developed as part of my VLSI Design learning journey.

Projects range from basic combinational and sequential circuits to advanced RTL modules such as:
- Adders
- Multiplexers
- Counters
- Shift Registers
- FSMs
- FIFOs

Each project includes RTL code, testbench, simulation waveform, and project documentation where applicable.
